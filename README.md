# SidhantPakhare.finance

Modern, responsive personal website for Sidhant Pakhare - FP&A Specialist

## Features

- ✨ Smooth animations with Framer Motion
- 📱 Fully responsive design
- 🎨 Modern minimal aesthetic
- ⚡ Built with Next.js 14 and TypeScript
- 🎯 Tailwind CSS for styling

## Getting Started

1. Install dependencies:
```bash
npm install
```

2. Copy your logo to the public folder:
```bash
copy "C:\Users\conta\Downloads\sidhantport.png" public\logo.png
```

3. Run the development server:
```bash
npm run dev
```

4. Open [http://localhost:3000](http://localhost:3000)

## Build for Production

```bash
npm run build
npm start
```

## Pages

- Home - Hero section with key achievements
- About - Professional story and skills
